# Audit of 2026-11-06

> **Documentation standard.** This document follows
> [`documentation-standard.md`](documentation-standard.md). Read it before editing this
> file, and check the result still meets it: measured claims only, rejected alternatives
> and corrections kept visible, and anything untested labelled as untested.

A lab record: the audit of every screen and function asked for by the maintainer on
2026-11-06 ("dont accept anything as fact and test all things ... we are working with
peoples save files here"), done together with the galaxy map that replaced the timeline. It
ran in rounds until a round found nothing new of weight: each round read the code
(read-only reviewers, each given one area or the changes since the last round), and the
program was driven at 1600 by 900 and at its minimum of 1280 by 780, with Large text, in
both games, in dark and light mode. The previous audit is
[audit-2026-11-02.md](audit-2026-11-02.md); its 55 fixes were re-read in round 1 and the
ones still wrong are below.

Marks: **T** measured by a test (named), **P** seen in the program, **R** read in the code.
Nothing here has been tried in the game: every finding is **untested in the game**.

## What was done to the program, and how it was driven

The tests open the saves on the PC read-only and change copies in memory or in the system's
temporary folder. The program was driven on the maintainer's real saves with no write: no
Save Changes, Copy, rename or Save as. Settings were changed (text size, light mode) and put
back to Large and Dark at the end.
